# 🚀 Frontpage

A modern **RSS and Atom feed reader** designed to help users organize, discover, and consume content without information overload.

---

## 🌐 Overview

Frontpage is a customizable content aggregation platform where users can follow their favorite blogs, newsletters, and publications in one clean and distraction-free reading experience.

The goal of this project was to build something closer to a real-world SaaS product rather than a typical frontend challenge. Instead of following a fixed design, I designed the entire experience from scratch — including UX, layout system, onboarding flow, and reading experience.

---

## ✨ Features

- 📰 RSS & Atom feed aggregation  
- 📊 Personalized reading dashboard  
- 🗂️ Categories and feed organization  
- ✔️ Read / unread tracking  
- 🔖 Bookmarks system  
- 🔍 Search functionality  
- 👤 Guest mode with curated content  
- 📱 Fully responsive layout  
- 🌙 Modern dark UI

## 🎨 Design Approach

Since no Figma file was provided, the entire product direction was created independently.

The interface was inspired by products such as:

- Notion  
- Linear  
- Medium  
- Readwise  

### Focus areas:
- readability first
- strong information hierarchy
- clean spacing system
- smooth navigation
- minimal visual noise

---

## 👤 Guest Experience

The application includes a **guest mode** with preloaded content so users can explore the product instantly without creating an account.

This helps make the experience more accessible and interactive from the first visit.
